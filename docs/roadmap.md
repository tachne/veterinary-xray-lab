# 第1段階の改良と今後の開発順序

更新日：2026年11月8日／対象：アプリv0.1.3・数式モデルv0.1.0

v0.1.3では合成テストパターンの追加と選択に対応した。本配布物はGitHub・Streamlit Community Cloud向けの公開準備版で、アップロードとデプロイは未実施である。担当教員による最終公開承認の後に[公開手順](deployment.md)へ進む。装置固有の物理的検証と学術的な正式承認は未完了であり、実装済み・試験合格という状態と区別する。試験内容と確認環境は[試験記録](test_results.md)に記載する。

アプリは条件・計算結果・画像・根拠を提示するツールとし、自動採点や教育評価を開発項目にしない。学生は実照射を行わず、仮想撮影と将来の教員配布データを扱う。

## 1. 開発順序と現在地

| 順序 | 範囲 | 状態・確認すること |
| --- | --- | --- |
| 1 | 第1段階のパターン追加 | **実装済み・公開準備中**。拡張512×512と従来の256×256を選択可能。Poisson生成則・物理モデル・強調・比較機能を維持。公開用構成の試験結果は試験記録を参照 |
| 2 | 合成ステップウェッジとROI | **未着手**。既知の段階信号と固定ROIを用い、平均・標本SD・SNR・CNR・厚さ対信号を扱う候補 |
| 3 | 適切な合成エッジとMTF | **未着手**。解析解を持つ斜めエッジからESF、LSF、pre-sampling MTF、MTF50、MTF10を検証する候補 |
| 4 | 教員配布のDICOM・実測データ | **未着手**。実測データの出所、信号特性、幾何・校正情報、匿名化を確認して解析する候補 |

次段階の機能を今回の改良に混在させない。先に第1段階の変更を検証し、その後の着手範囲を別途決める。実測データが未確認でも合成データによる準備は可能だが、合成データの検証を実機の妥当性検証とは扱わない。

## 2. 今回の改良で確認すること

- モデル版v0.1.0とPoisson生成則を維持する。パターンの選択は期待信号Sと画像配列を変えるが、K・EI/DI・S=1理論ノイズ・SNRは変えない。
- 拡張512×512の左上へ旧256×256の期待信号を完全に保持する。右上にポメラニアン風の細部、下部に幅・間隔8/6/4/3/2/1画素、信号0.30/0.90の線対6群を配置する。
- 旧256×256も選択可能とし、すべての比較画像へ現在の選択パターンを共通適用する。基準・保存記録の条件とseedを保ち、保存時と表示時のパターン情報を分ける。
- 既存のJ=S+g(I−S)、強調係数1/2/3/5、seedモード、手動再生成を維持する。表示操作だけで定量配列を変更しない。
- 表示倍率1/2/4で選択画像の全体/中央1/2幅/中央1/4幅を最近傍法で拡大する。固定窓0–1.2・共通階調・表示領域内クリップ率を維持する。
- ぼけ関数は追加しない。細線の見え方とノイズ・粒状性・鮮鋭度を区別し、線対の目視をMTF測定としない。
- 犬の撮影配置模式図、最大8件の比較記録、CSV、版情報の追跡を維持する。ポメラニアン風パターンも配置模式図も、犬の解剖・診断像として扱わない。
- 数式・表示・比較の既存試験を維持し、パターン構成、従来の期待信号の保持、共通パターンでの比較、記録の出所を確認する。合成パターンの試験合格を学術的・実機的な妥当性の承認として扱わない。

公開用構成ではアプリと計算コアの機能を維持し、起動設定・依存関係・文書を配布用に整理する。Cloud上の動作と授業規模での同時利用は未検証であり、公開後に確認する。新規課題・採点機能は追加しない。

## 3. 合成ステップウェッジとROIの準備

段階的な減弱・信号・コントラストの関係を扱う。最初は既知の期待信号から作った合成画像を使用し、固定ROIの画素数、平均、標本SD、信号のオフセット、分散モデルを記録する。物質の厚さを入力にする場合は、その物質の減弱係数と線質の根拠を別途定め、現行の一様体厚用μをアルミニウム等へ流用しない。[NIST減弱則](https://physics.nist.gov/PhysRefData/XrayMassCoef/chap2.html)

SNR/CNRの式は信号の線形性とROI・分母の定義を固定してから実装する。ノイズゼロ、ROI不足、飽和、構造を含むROI等では不適切な数値を返さない。これは次段階の候補であり、v0.1.3にROI統計解析はない。中央領域の切り出しとクリップ率表示は、SNR/CNRのROI測定とは区別する。

## 4. 合成エッジとMTFの準備

今回追加する線対パターンは見え方の比較用であり、この段階には進まない。独立したぼけモデルを扱うかどうかも、将来のMTF設計と合わせて別途検討する。

ステップウェッジや犬の臓器境界を流用せず、適切な専用斜めエッジを用いる。エッジ位置・角度の推定、法線方向への投影、細分ビンによるESF、微分によるLSF、窓処理、フーリエ変換とDC正規化を設計する。処理自体の伝達特性を確認し、差分やビン分けの補正を一律に適用しない。[Sameiほか](https://aapm.onlinelibrary.wiley.com/doi/10.1118/1.598165)、[Greer・van Doorn](https://pubmed.ncbi.nlm.nih.gov/11011732/)

画素間隔p mmに対する軸方向のナイキスト周波数1/(2p)と、細分化したESFの間隔を区別する。MTF50・MTF10の交差が解析範囲内で得られない場合は「未到達」とし、外挿や境界値への置換を行わない。ノイズ増加による推定値のばらつきを、装置固有MTFの低下と解釈しない。解析解を持つ合成エッジで角度・ROI・ノイズ・窓幅への感度を検証する。[AAPM TG-162](https://aapm.onlinelibrary.wiley.com/doi/abs/10.1002/mp.12718)

## 5. 教員配布のDICOM・実測データへの移行

学生は画像を取得するための照射を行わず、教員が確認したデータを解析する。受入時に、装置・検出器、取得条件、線質、画像処理、画素間隔と基準面、校正情報、測定不確かさ、利用範囲を記録する。

原画素、定量解析用の信号、表示画像を分ける。For Processingという名称だけで線形性を判断せず、信号応答と処理履歴を確認する。患者側Pixel Spacingと検出器側Imager Pixel Spacing、装置記録EIと教材計算EIを区別する。[DICOM DX Series](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.8.11.html)、[Pixel Spacing Calibration](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_10.7.html)

個体・飼い主・施設等の識別情報、私有属性、画素中の文字、オーバーレイを含めて匿名化を確認する。タグの削除だけで画像内情報まで除去したとは判断しない。データが利用できることと、目的の解析に適していることも別に判定する。[DICOM Confidentiality Profile](https://dicom.nema.org/medical/dicom/current/output/chtml/part15/sect_E.2.html)、[Clean Pixel Data](https://dicom.nema.org/medical/dicom/current/output/chtml/part15/sect_E.3.html)

これらの入力・解析は今回実装しない。実機条件の自動推奨、患者線量や診断可否の自動判定は、上記の計算・画像評価機能とは別の問題として対象外に置く。
