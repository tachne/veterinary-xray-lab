# 獣医X線撮影条件・画質評価シミュレーター 基本設計書

版：v0.1／作成日：2026年11月7日／状態：第1段階・ひまりによる学術・教育レビュー依頼用／教員の正式承認は保留

## 1. 目的と責任範囲

獣医学部学生が、撮影条件から検出器入射空気カーマ、EI・DI、量子ノイズまでの関係を、条件を一つずつ変える仮想撮影によって説明できるようにする。学生は本実習で実際のX線照射を行わず、撮影条件の操作はシミュレーター内だけで行う。画質と被ばく低減を考察する基礎教材であり、診断画質の合否判定、患者線量の推定、実際の動物への撮影条件の自動推奨は行わない。

教育企画・学術的監修・品質評価はChatGPT「ひまり」、設計・実装・テストはChatGPT Work「真理」、教育内容の承認と最終判断は担当教員が担う。現在はひまりへの学術・教育レビュー依頼段階であり、レビューの結論や学術的妥当性の承認は記録していない。教員の正式承認は保留中である。第2段階は設計準備のみとし、正式な開始承認が記録されるまで測定・解析機能を実装しない。

実測データを扱う将来の演習では、教員がステップウェッジ画像等を配布し、学生は配布データの解析に取り組む。学生自身の照射や撮影によるデータ取得は行わない。利用可能な実測データが確認されるまでは合成データを使用し、実測データとして扱わない。本版には実測データの読み込み・解析機能を含めない。

教育全体ではEI、DI、ノイズ、SNR、CNR、MTFの理解を目標とする。各項目の現在の実装範囲と将来案を次のように区別する。

| 学習項目 | 第1段階で扱う内容 | 正式承認後に検討する内容 |
| --- | --- | --- |
| EI・DI | 校正関係を仮定した計算、目標EIとの差、装置依存性 | 教員配布データや装置情報との対応確認 |
| ノイズ | Poissonモデルの理論値、模擬画像の比較 | 配布画像のROIからの評価、実測値との比較 |
| SNR | 単位信号の一様領域に対する理論値 √N | ROIに基づく画像解析と採用定義の明示 |
| CNR | 未実装。低コントラスト模擬パターンの観察はCNR測定ではない | 対象・背景ROIとノイズ定義を定めた評価 |
| MTF | ノイズとの概念上の区別。数値測定は未実装 | 専用エッジ画像からのSlanted-edge解析 |

第1段階の到達目標は次のとおり。

- mAsの比例則、SIDの逆二乗則、体厚の増加による透過率の変化を、モデルの仮定付きで説明する。
- EIが検出器への露出の指標であり、患者被ばく線量そのものではないと説明する。
- DIの符号と対数尺度を読み取り、DI = 0だけで診断に十分な画質とは判断できないと説明する。
- 理想一様領域のSNRと相対量子ノイズの関係を説明し、画像全体の診断性能と区別する。
- 量子数増加による相対量子ノイズの低下と、空間分解能を表すMTFを区別する。
- 規格に基づく定義、物理的近似、仮定値、実測値の区別を付けて結果を報告する。

## 2. 第1段階の提供範囲

PythonとStreamlitによるローカル実行のWebアプリケーションとする。画面の文言と教材は日本語を基本に、kVp、mAs、SID、EI、DIなどの専門記号を併記する。

提供するのは仮想撮影と合成画像の比較である。実測画像・DICOMの読み込み、ROI解析、CNR算出、MTF算出は未実装であり、今回のレビュー資料作成によって実装範囲を追加しない。

| 入力 | UIの範囲 | 単位・意味 | 扱い |
| --- | --- | --- | --- |
| 管電圧 | 40–120 | kVp | 教育用操作範囲 |
| 管電流時間積 | 0.1–20 | mAs | 教育用操作範囲 |
| 焦点–検出器間距離 | 50–200 | cm、SID | 教育用操作範囲 |
| 体厚 | 0–35 | cm | 一様な減弱体の厚さ |
| 目標EI | 1–5,000 | 無次元 | 演習用の仮定値、臨床目標ではない |
| モデルパラメーター | 妥当性検査付き | 出力係数・減弱係数など | 仮定値を明示 |

入力範囲は装置や動物種に対する推奨撮影条件ではない。係数の初期値はすべて仮定値であり、実測データは本版に含めない。SIDは焦点から検出器までの距離であり、焦点–皮膚間距離として扱わない。

基準管電圧80 kVpと基準SID 100 cmは本版の画面では固定する。基準出力、出力のkVp指数、実効減弱係数とそのkVp指数、仮想グリッド透過率、仮想計数換算係数は「仮定したモデル係数」から変更できる。係数の変更は、装置の校正や実測値の登録を意味しない。

## 3. 画面と学習の流れ

1. 教育用モデルであることと主要な制限を確認する。
2. 仮想撮影条件を操作し、検出器入射空気カーマの推定値、モデルEI・DI、量子数、相対量子ノイズ、理論SNRを読む。
3. 条件とノイズの関係をグラフで確認し、理想ファントムと量子ノイズを付加した模擬画像を比較する。
4. 条件を保存して、表で最大8件を比較する。そのうち最大4件を選んで模擬画像を並べる。設定、単位、モデル値、乱数シードも比較結果に含める。
5. 全パラメーターを含むCSVを保存する。条件変更の理由、観察した変化、モデルの制限は授業ワークシート等に記述する。

模擬画像は幾何学的なパターンで作る。実際の動物のX線像や検出器で撮影した実測画像には見せない。これはステップウェッジの実測像でも、MTF測定用の専用エッジ画像でもない。全条件に同じ表示ウィンドウを用い、自動階調調整がノイズ比較を隠さないようにする。内部の線形画像と表示時のクリッピングは分ける。画像の外観は診断能やMTFの検証に使わない。

乱数シードを保存し、同じ設定と同じシードで画像を再現できるようにする。「ノイズを再生成」は同じ理論値でも模擬画像が変動することを示す。異なる量子数で同じシードを用いても、同一のノイズ画像を単に倍率変更したものではない。

画面は「模擬画像を観察」「応答曲線を読む」「条件を比較」「モデル・学習資料」の4タブで構成する。応答曲線はkVp、mAs、SID、体厚から横軸を選び、ほかの入力を固定したカーマ、EI、DI、相対量子ノイズを示す。比較表は撮影条件・主要結果を表示し、画像を選択した記録の詳細から全係数を確認できる。記録間でモデル係数や目標EIが異なる場合は、その旨を表示する。

比較結果は現在のブラウザーセッション内で保持し、選択した記録を削除できる。CSVの再読み込み、保存条件のサイドバーへの復元、永続的な症例管理、複数利用者間の共有は第1段階に含めない。

記録を追加すると画像選択は直近2件に更新する。仮想計数が画像生成範囲（10⁻⁹～10¹²個/画素）外の場合は、説明を表示して該当画像のみ非表示とし、計算値・曲線・比較記録は保持する。計数の切り上げで画像を作らない。

## 4. 計算と表示の分離

```text
Streamlit入力
  → 型・範囲・有限値の検査
  → physics：決定論的な物理モデル
  → imaging：理想パターン＋Poisson標本化
  → 数値・グラフ・固定ウィンドウ画像
  → セッション比較・CSV
```

| ファイル | 責務 |
| --- | --- |
| `app.py` | UI、表示文言、セッション、比較、CSV出力 |
| `simulator/physics.py` | 入力データ型、カーマ・EI・DI・量子ノイズの計算と検査 |
| `simulator/imaging.py` | 理想ファントム、再現可能なPoisson画像、表示変換 |
| `simulator/comparison.py` | 全入力を保持した比較記録、版・保存日時・由来、CSV出力 |
| `tests/test_physics.py` | 定義式、理論比、異常入力の単体試験 |
| `tests/test_imaging.py` | 画像再現性、統計的挙動、表示変換の試験 |
| `tests/test_app.py` | 起動、操作、比較などの画面ロジックの試験 |
| `docs/physics_model.md` | 数式、単位、出典、校正条件、仮定と限界 |
| `docs/test_results.md` | 実施した試験と結果、未確認事項 |
| `docs/roadmap.md` | 残課題、第2段階の設計準備、承認条件 |
| `README.md`、`requirements.txt` | 起動・試験手順、実行依存関係 |

中心となるデータ契約は次のとおり。演算関数はStreamlitの状態を参照しない。

| データ | 主な項目 |
| --- | --- |
| `ExposureSettings` | `kvp`、`mas`、`sid_cm`、`thickness_cm` |
| `ModelParameters` | 基準出力、基準kVp・SID、kVp指数、基準減弱係数、減弱係数のkVp依存指数、グリッド透過係数、目標EI、カーマ当たりの仮想量子数 |
| 計算結果 | `detector_kerma_ugy`、`ei`、`di`、`effective_mu_per_cm`、`transmission`、`mean_quanta`、`relative_noise`、`snr` |
| 比較スナップショット | 保存時の設定、全モデルパラメーター、計算結果、乱数シード、記録ID・ラベル、保存日時（Asia/Tokyo）、モデル版、仮定値の注記、画像寸法・表示窓 |

保存後のスナップショットは入力の変更に追随させず、保存時点の値を維持する。画像は保存した仮想計数とシードから再生成する。CSVはUTF-8 BOM付きで、設定・係数・結果を階層名付きの列に展開し、単位と仮定モデルであることがわかる列名・情報を保持する。記録名が表計算ソフトで式として扱われないよう、該当する文字列をエスケープする。

## 5. 物理モデルと説明上の制約

検出器入射空気カーマは、基準出力にmAs比例、kVpのべき乗、SID逆二乗、体厚の指数減弱、透過係数を掛けた簡易モデルで推定する。多色X線のスペクトル、散乱、ビームハードニング、組織構成、AEC、画像処理などは扱わない。数式、係数の意味、校正条件は[物理モデル説明書](physics_model.md)を参照する。

EIはIECの校正関係を教材として用いる。一般の臨床画像で、この簡易モデルから実機のEIを正確に予測できるとはしない。DIの目標EIは演習用設定であり、装置・部位・診断目的について承認された臨床目標ではない。

Poissonモデルでは量子数に応じて相対ノイズが変わる。固定パターンの形状やぼけは撮影条件で変化させず、線量増加によってMTFが向上するという説明をしない。実機の非線形処理や低信号域などにおける特性は別途検証を要する。

## 7. 学術・教育レビュー用の演習例

以下はいずれもシミュレーター内の仮想撮影であり、学生による実照射を伴わない。

| 演習 | 変更 | 学生が説明する内容 |
| --- | --- | --- |
| mAsの効果 | ほかを固定して2倍・4倍 | KとEIは2倍・4倍、相対ノイズは約0.707倍・0.5倍になる理由 |
| 距離の効果 | SIDを100 cmから200 cm | KとEIが1/4になる仮定、相対ノイズが2倍になる理由 |
| 厚さの効果 | 同じkVpで体厚を段階的に増加 | 指数減弱と、実際の組織や散乱を省略している制限 |
| DIの読み方 | 目標EIのみ変更 | 画像・カーマが同じでもDIが変わる理由、DIが患者線量でない理由 |
| ノイズの確率性 | 同じ条件でノイズを再生成 | 理論値と一枚の画像の変動の違い |
| SNRの読み方 | mAsを4倍 | 理論SNRが2倍、相対ノイズが1/2になる理由と、評価領域の前提 |
| 指標の限界 | 同じEIの条件を比較 | EIだけで診断画質・患者線量・MTFを決定できない理由 |
