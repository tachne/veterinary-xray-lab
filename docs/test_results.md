# 公開前の検証結果

実施日：2026年11月8日。対象：v0.1.3を基準とするStreamlit公開準備版。

**106試験・88 subtest合格。失敗・エラー・スキップ0。** 既存103試験のファイル・期待値を変更せず、新規3試験を追加した。GitHubへのアップロード・Community Cloudへのデプロイは行っていない。

macOS / Apple Siliconで、既存のsite-packagesを共有しない新規Python 3.13.0仮想環境を作成した。user siteも無効であり、宣言した依存関係をpipで導入した。

```text

```

再実行はプロジェクト直下で、作成した仮想環境を使用する。

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m pip check
python -m streamlit run app.py
```

Linux x86-64・CPython 3.13を指定したpipのbinary-only依存解決も実施し、manylinux/pure-Python wheel計34個を取得できた。これは配布物の入手・解決確認であり、Linuxでの実行試験やCommunity Cloud上での起動確認ではない。間接依存の全版を固定したものではないため、公開時には導入ログを確認する。

## 機能と独立性

| 確認 | 結果 |
| --- | --- |
| 既存103試験 | EI/DI・物理モデル、Poisson統計、強調の独立性、線対・犬、入力操作、曲線、比較、CSVを維持 |
| 3つのAppTestセッション | 入力、記録名、保存値、seed、固定基準、表示、削除、生成CSVが混在しない |
| 並列の計算・画像生成 | 4ワーカー・8要求が逐次処理と計算値・画素単位で一致。グローバル乱数状態と返却配列の非共有を確認 |
| 別の作業ディレクトリからの起動 | `app.py`の位置を基準としてPNG・SVGと同梱文書を読込可能 |
| 実ブラウザーの2セッション | Aは5 mAs・seed42、Bは20 mAs・seed43。片方の変更後も相手の入力・記録を維持 |
| 実CSVダウンロード | A/Bとも各1行・51列で自身の記録だけを取得。K比4、理論相対ノイズ比0.5、全条件・版・表示情報を照合 |

AppTestは独立セッションを交互に逐次操作した検証である。純計算の並列試験と、実ブラウザー2接続の確認を組み合わせたが、授業人数での同時負荷・性能の保証ではない。

## ファイルと公開範囲

- 基準版v0.1.3の77ファイルを別に保存し、元ファイルのSHA-256と保存ZIPの整合性を確認した。
- 公開用の`app.py`、計算・画像モジュール、SVG素材、既存テストの計18ファイルは基準版とバイト単位で一致する。物理式・画像処理・UI機能は変更していない。
- 公開用の設定からローカル固定アドレス・ポートを除去し、実行依存とpytestを分離した。画像・模式図は同梱し、OS固有フォントやMac絶対パスは不要。
- `.gitignore`をGit自身で照合し、仮想環境・キャッシュ・Secrets・秘密鍵・個人CSV等20例の除外と、公開必須9パスが除外されないことを確認した。
- アプリ本体と必要素材、テスト、説明・手順だけを配布対象にした。旧成果物、ダウンロードCSV、試験XML、ホスト名・ローカル絶対パスを含む生ログ、仮想環境、取得wheelは公開対象外に分離した。
- 公開候補のソースとSVGを確認し、秘密情報の典型パターン、個人環境への参照、SVGの外部読込・スクリプトを検査した。検査で該当は見つからなかったが、将来追加するファイルまで安全と保証するものではない。

入力・比較記録は接続ごとのメモリー内に保持し、アプリ独自の入力ファイル保存・データベース保存・ログ記録は行わない。ホスト側のアクセス記録や利用統計まで停止することはできない。[Cloudの制約](https://docs.streamlit.io/deploy/streamlit-community-cloud/status)
