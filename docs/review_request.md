# ひまり（ChatGPT）への学術的・教育的査読依頼

対象：獣医X線撮影条件・画質評価シミュレーター v0.1、第1段階。
資料作成日：2026年11月7日（Asia/Tokyo）。

**状態：教員による正式承認は保留。ひまりによる査読結果は未受領。第2段階の実装には進まない。** 本書は査読依頼と確認項目の整理であり、査読済みとの判定ではない。

## 確定した教育方針

1. 学生には実際のX線撮影を行わせない。
2. 学生はWebアプリ上で仮想撮影を行い、撮影条件と画質の関係を学ぶ。
3. 教員が配布するステップウェッジ等の実測画像を解析する。
4. EI・DI、ノイズ、SNR、CNR、MTFを学習対象とする。
5. MTFには適切なエッジ画像を用い、ステップウェッジによる減弱・コントラスト評価と区別する。
6. 実測画像が見つかるまでは合成画像を用いて開発・検証する。ただし、第2段階の実装開始は査読と教員判断を待つ。

教育方針は確定しているが、学術的妥当性・授業利用・次段階開始の承認は未確定である。

## 特に確認してほしい事項

### EI・DIの定義と表示

- `EI = c₀ g(V)`という規格の定義と、校正条件下の比例関係を本モデルに仮定した計算を十分区別できているか。
- `EI_sim = 100 × K_det[µGy]`、`DI = 10 log10(EI_sim/EI_T)`の単位・適用条件・説明は妥当か。
- EIを患者被ばく線量と誤認させないか。DI = 0を診断画質の合格判定と受け取らせないか。
- EI校正条件・線質依存性・関心領域選択・装置依存性の説明は十分か。IEC本文の公開範囲外について、説明書が明示した未照合事項をどう補うか。

### 入射空気カーマ・量子数モデル

- mAs比例、逆二乗則、kVpべき乗、実効減弱係数による指数減弱を組み合わせたモデルは、目的とする学習に対して適切か。
- 出力・減弱・グリッド・計数換算等の値がすべて仮定であることは明確か。初期値と操作範囲を修正すべきか。
- 散乱、多色スペクトル、ビームハードニング、エネルギー応答等を省略した影響を、学生にどこまで説明すべきか。
- 検出器入射空気カーマ、検出器内吸収線量、患者線量の区別に不足がないか。

### ノイズ・SNR・CNR・MTFの区別

- 絶対ノイズ、相対ノイズ、理論SNRの説明と、信号1の均一領域を基準とする表示は適切か。
- 固定表示窓、Poisson標本化、乱数seed、局所信号依存性、表示クリッピングの扱いは教育上妥当か。
- 本版のSNRは理論値のみである。将来の画像ROIからのSNR/CNR評価では、背景・信号領域、ノイズ推定法、用いる定義をどう定めるか。CNRは未実装であり、計算式の採用も今後の査読対象とする。
- MTFを空間周波数応答、ノイズを確率的変動として説明し、ノイズ低下をMTF向上と混同していないか。
- ステップウェッジとMTF用エッジ画像の目的・取得条件・解析法を明確に分けられているか。

### DICOM画像の扱い（未実装の設計査読）

現行アプリにはDICOM読込・匿名化・タグ解析・画像解析機能がなく、同梱DICOMファイルもない。以下は将来の設計で検証してほしい事項であり、規格適合や処理の正しさを確認済みとはしない。

- 教員配布データの出所、利用許可、識別情報・画像内文字の扱い、匿名化確認の責任をどう定めるか。
- 対象SOP Class、転送構文、圧縮、フレーム数、ビット深度、符号、欠損値等をどう制限し、非対応データをどう扱うか。
- 保存画素値、画素値変換、表示用ウィンドウ/LUT、反転表示、画像処理履歴をどう区別するか。for-processing / for-presentationの区別やタグの有無だけで解析適性を判断してよいか。
- 画素間隔のタグ、値の参照面、拡大・再標本化・ビニング、縦横の違いをどう確認し、MTFの単位換算に使うか。
- EI・目標EI・DI等のタグ、単位、欠損、メーカー固有指標をどう照合するか。モデルから求めた値との混同をどう防ぐか。
- 原画素の保持、解析用変換の記録、ROI、飽和・欠損、線形性、校正情報をどのように追跡可能にするか。
- 合成データでの試験を、どの条件で教員配布の実測データによる検証へ移すか。

採用するDICOM規格の版・該当箇所・メーカー資料の照合と処理仕様の決定は、査読と教員判断後の課題とする。
