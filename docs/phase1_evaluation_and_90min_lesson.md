### 1.2 学術的な評価と誤解が生じる箇所

現行コードと文書の間に明らかな数式の取り違えは見つからなかった。以下の多くは開示済みの近似であり、数式の修正よりも、学生が観察する画面と授業説明の対応を優先する。

| 対象 | 確認結果 | 説明で補う点・適用限界 |
| --- | --- | --- |
| mAs | 他条件固定でK・仮想計数Nに比例 | 安定した出力と一定線質を仮定する。飽和、電子雑音、実機の出力非直線性は含まない |
| SID | KはSIDの二乗に反比例 | 点線源、固定減弱の近似。焦点・皮膚間距離とは異なり、拡大や幾何学的ぼけを計算しない |
| kVp | 出力をkVpのn乗、減弱係数をkVpの−p乗と仮定 | n=2、p=1は仮定値。被写体があるとKは単なるkVpの二乗にならない。精密な線質・組織コントラストの再現ではない |
| 体厚 | 固定kVpでexp(−μt) | 一様物質の実効係数。犬の組織やアルミニウムの実測値ではなく、線質硬化・散乱線を含まない |
| EI・DI | 定義式とモデル内の計算は整合 | 本版のEIはモデルKから算出する教材値。実画像の領域選択・装置校正は未実施。EIは患者線量でなく、DI=0は画質合格を意味しない |
| 量子ノイズ・SNR | 独立Poisson計数に整合 | N=qKのqは仮定した一定値。実際のカーマと光子数の換算はエネルギーに依存する。表示SNRは画像全体の診断性能ではない |
| 画素値・MTF | 画像は規格化信号、MTFは未計算 | 明るさが一定でも入射量は変わる。ノイズ低下で線が見やすくなることをMTF向上と扱わない |

指数減弱の基礎は単色・狭い線束に対する関係である。今回の広い操作範囲（40〜120 kVp等）はUI上の設定範囲であり、実機で検証した適用範囲ではない。[NIST：減弱則](https://physics.nist.gov/PhysRefData/XrayMassCoef/chap2.html)、[NIST：エネルギーフルエンスとカーマ](https://physics.nist.gov/PhysRefData/XrayMassCoef/chap3.html)

**EI・DIの授業用説明：** IECでは`EI = c₀ g(V_img)`、`c₀ = 100 µGy⁻¹`。画像領域の代表値`V_img`に装置固有の逆校正関数を適用する。校正条件では`EI = 100 × K_CAL[µGy]`、`DI = 10 log₁₀(EI/EI_T)`となる。本版は校正比例関係を全条件に仮定した`EI_sim = 100 × K_det[µGy]`であり、画像から実機EIを求めていない。均一照射、規定線質、後方散乱を除いた測定等の校正条件が必要で、単に80 kVpに設定しても校正にはならない。[IEC 62494-1:2008 公開本文 §4.3–4.7](https://cdn.standards.iteh.ai/samples/15501/db401edecbb94545a49f023514805abf/IEC-62494-1-2008.pdf)

**ノイズの授業用説明：** 局所の理想信号をS、計数をCとすると、本版は`C ~ Poisson(NS)`、保存用の線形信号は`I = C/N`である。したがって`平均C = NS`、`SD(C) = √(NS)`、`平均I = S`、`SD(I) = √(S/N)`。計数の絶対SDは増えても、相対ノイズ`1/√(NS)`は減る。画面上のノイズとSNRは外周の一様なS=1領域に対する理論値で、各構造の局所SNRは異なる。複数構造を含む画像全体のSDを、そのままランダムノイズにしない。[IAEA Diagnostic Radiology Physics §4.5.1](https://pub.iaea.org/mtcd/publications/pdf/pub1564webnew-74666420.pdf)

PNGは表示窓0〜1.2でクリップ・8ビット化した閲覧用であり、定量用の未クリップNPYと区別する。現版ではkVpを変えても理想信号Sの形状・コントラストは固定され、変化するのはモデルKに基づく計数である。デジタル画像の表示の明るさから入射量を直接判断しないことは、EIの学習にもつながる。[同梱データの説明](/Users/kakizaki/Documents/ChatGPT/撮影条件設定実習/samples/README.md)、[AAPM TG116](https://www.aapm.org/pubs/reports/rpt_116.pdf)

### 1.3 ステップウェッジ・MTF・DICOMの扱い

初回90分は理論SNRと模擬画像観察までとし、ROI・CNR・MTFの定量実習は次の授業候補とする。実測画像が見つかるまで開発を止める必要はないが、着手には別途教員判断を要する。

| 将来の最小候補 | 学ぶ内容・先に確定する条件 |
| --- | --- |
| 合成ステップウェッジ | 各段の一様領域に固定ROIを置き、平均・標本SD（分母n−1）・SNR・CNR・厚さ対信号を比較。アルミニウム厚の仮定と減弱係数の根拠を記録し、現在の体厚用μを流用しない |
| SNR・CNRの定義 | オフセット補正済み線形信号でSNR=平均/SD。CNRは候補として「段と背景の平均差の絶対値/背景SD」を採用し、背景ROIを固定する。絶対値は大きさとして報告する教材上の選択。別の分母定義と混用せず、SD=0では算出しない |
| 合成slanted-edge | ウェッジとは別画像を使用。ESF→LSF→MTF、画素間隔とナイキスト周波数を扱う。既存の線状パターンの目視をMTF測定の代用にしない |
| 教員提供DICOM | 保存画素値・表示変換・信号の線形性・処理履歴・画素間隔を確認。For Processingの名称だけで線形性を保証しない。保存されたEIと教材の計算EIを区別し、個体・飼主情報や画面内文字を確認して配布する |

CNRの候補は[AAPM TG150 §4.3.15](https://www.aapm.org/pubs/reports/TG-150_final.pdf)を参考とする。処理状態が不明な画像の測定結果は、検出器固有のpre-sampling MTFと表示しない。DICOMにもLIN/LOGや信号の増減方向の区別があり、画素値を無条件に線量へ換算できない。[DICOM DX Image Module](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.8.11.3.html)

### 3.3 学生用：課題

**課題1：mAsと量子ノイズ（20分）**

1. AからBへ変更する前に、上の予測欄を記入する。仮想計数N、計数の絶対SD、相対ノイズがどう変わるかも予想する。
2. A・Bを保存し、数値・同じ領域の粒状性・mAsの応答曲線を比較する。
3. 予測と結果が一致した点、違った点を説明する。「画像の平均的な明るさがほぼ同じでも、入射量が同じとは限らない」理由を、C_iとI_iの違いから述べる。見た目だけでノイズ比を正確に測定できたとはしない。

**課題2：EI・DIは何を表すか（20分）**

1. 校正条件でK_CAL=2.5 µGyのEIを求める。次に目標EI=250として、EIが125、250、500のDIを求める。式は`EI=100×K_CAL[µGy]`、`DI=10 log₁₀(EI/EI_T)`。
2. mAs=1、SID=100 cm、目標EI=250へ手動で戻す。AのKから教材EIとDIを計算し、表示と照合する。目標EIだけを500にする前に変化を予測し、Tを保存してAと比較する。
3. 「DIが負なら再撮影が必要」「DI=0なら診断に十分」「EIは患者線量を示す」という説明を検討する。予測と観察の違い、または一致した理由を述べる。

**課題3：撮影条件と画質を、指標の限界も含めて考える（20分）**

1. 目標EIを250へ戻す。Aに対しSIDだけを200 cmにしたCを予測・記録し、逆二乗則とノイズの変化を照合する。
2. SID=200 cmのまま、Aと同じモデルKにするmAsを予測する。予測を記入してから教員と設定値を確認し、Dを記録してA/C/Dを比較する。
3. 「AとDのEIが同じだから患者線量も同じ」「細い線が見やすくなったからMTFが改善した」という結論の妥当性を検討する。予測と結果の対応を述べ、本モデルが扱わない要素を2つ以上挙げる。

**終了課題：** 「分かった関係1つ」「修正した予測または新たに気づいた限界1つ」を各1文で書く。数値が一致しても理由を省かない。5記録のCSVと、予測・結果・考察を記した回答シートを教員指定の方法で提出する。

### 3.4 教員用：解答・評価の要点

以下は仮定したモデルによる期待値であり、実測・臨床条件ではない。今回のAppTest実行結果と照合済み。
